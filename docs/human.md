# Initial Description of Project

## Preface

This file contains the initial description, and requirements of `AIchemist-desktop-buddy`, and is 100% written by a human.

## Description

`AIchemist-desktop-buddy` is a small application intended for running all the time.
It should have a small memory footprint.
The desktop buddy is a small avatar of a pet (initial tought is a gray tabby cat). It should be animated, and have various states, like thinking, idle, etc.
The desktop buddy should be cross platform, with MacOS and Windows being the only _actual_ required platforms.
The desktop buddy should remind the user of the next meeting in their calendar (msgraph and caldav support first).
The desktop buddy should be able to remind the user of tasks (we might need to define how this should work).
The desktop buddy should include a settings view, so the user can edit any settings needed.
